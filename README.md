This small Win64 solution fixes the error "scarletbook_read_master_toc: Not a ScarletBook disc!"
It leverages the solution proposed here: https://github.com/sacd-ripper/sacd-ripper/issues/80, and merely translates it to a Windows application.
You can select input and output file, see progress, and don't have to fiddle around with Cygwin or Powershell.
